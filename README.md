# phone-ruler
Полупрозрачная экранная оверлей-линейка на PyQt6 и Windows Magnification API для операторов колл-центров и ввода данных. Оптическая лупа (1.25x–4x), настраиваемые разделители блоков под шаблоны номеров РФ и карт, поддержка DPI-масштабирования и быстрое автозаполнение полей по горячим клавишам.
