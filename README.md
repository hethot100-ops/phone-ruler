# phone-ruler
PhoneRuler — Экранная линейка, оптическая лупа и OCR-кликерЛегковесная экранная утилита поверх всех окон (Always-on-Top) для операторов колл-центров, диспетчеров и операторов CRM/удаленного рабочего стола. Утилита позволяет визуально выравнивать телефонные номера, банковские карты или артикулы по настраиваемым сегментам сетки, масштабировать мелкий шрифт встроенной оптической лупой Windows Magnification API и автоматически считывать и впечатывать распознанный номер в активное поле ввода по горячей клавише.🌟 Основные возможностиАдаптивная сетка-разделитель:Индивидуальная настройка положения, высоты и формы меток (|, ( ), [ ], { }, стрелки, засечки).Готовые шаблоны: РФ/СНГ (+7 (XXX) XXX-XX-XX), скобки, компактный (3-3-4), банковские карты (4×4).Свободное растягивание мышью за края и углы с пропорциональным масштабированием делений.Аппаратная оптическая лупа (Windows Magnification API):Масштабирование без размытия (от 1.25x до 5.0x).Цветовые фильтры: инверсия, оттенки серого (Ч/Б), обычный.Прямая синхронизация с линейкой без смещений.Стилизация интерфейса:40 визуальных стилей обводки (включая неоны, градиенты, анимации «Лава»/«Северное сияние», Minecraft-блоки, Terraria, Stardew Valley, Zelda и граненый Кристалл MOBA).Каталог превью стилей (StylePreviewDialog) с живым рендерингом.Темы контекстных меню: Dark, Light, Neon, Glass, Minimal.Автоматизация и OCR (Распознавание + Ввод):Окно линейки исключено из системного захвата экрана (WDA_EXCLUDEFROMCAPTURE), что исключает попадание рамки и делений на снимок при распознавании.Двухуровневый консенсусный OCR-пайплайн: Tesseract OCR (приоритетный) + Windows.Media.Ocr (резервный системный).Автоматический фокус на предыдущее активное окно и эмуляция нажатий клавиш через WinAPI SendInput.⌨ Горячие клавишиХоткейДействиеF9 или Ctrl + Shift + VРаспознать цифры под линейкой и напечатать в активное полеTРучной запуск OCR и печатиMВключить / выключить оптическую лупуIПереключить цветовой режим лупы (Нормальный / Инверсия / Ч/Б)GПоказать / скрыть сетку с разделителямиHПоказать / скрыть центральную осевую линию высотыR / Alt + Колесо мышиБыстрая смена цвета обводки из палитры+ / - 🔍 Настройка движка распознавания (Tesseract OCR)Для максимальной точности и скорости работы OCR рекомендуется использовать движок Tesseract OCR. Если Tesseract не установлен, приложение автоматически переключается на встроенный системный модуль Windows.Media.Ocr.Шаг 1. Установка Tesseract через winget (рекомендуется)Откройте терминал PowerShell или командную строку (CMD) и выполните:PowerShellwinget install UB-Mannheim.TesseractOCR
Шаг 2. Ручная установка (альтернатива)Перейдите в официальный репозиторий сборок для Windows: UB-Mannheim Tesseract Wiki.Скачайте инсталлятор tesseract-ocr-w64-setup-v5.x.x.exe.Запустите установку и сохраните стандартный путь:PlaintextC:\Program Files\Tesseract-OCR\tesseract.exe
В окне выбора компонентов раскройте раздел Additional language data / Additional script data и отметьте Russian и Cyrillic script.Шаг 3. Активация встроенного Windows OCR (резервный вариант)Если вы работаете в изолированной среде без возможности установки внешнего ПО, включите системный пакет распознавания текста через PowerShell (от имени администратора):PowerShellAdd-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
